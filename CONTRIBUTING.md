# Contributing

Open an issue to discuss hardware support or changes to the packet path. Include
sanitized diagnostics from Lekuo Control; omit addresses, serial numbers,
private machine names, signed profiles, raw packet captures, and account data.

Use a GitHub noreply email for commits. Keep your chosen public author name;
anonymous shared author identities are not required. Run
`python3 scripts/check_public_source.py` before pushing. This checks common
private data in the working tree and reachable Git history, but cannot replace
review of what you are publishing.

On a compatible Mac with Xcode, run `bash scripts/test_local.sh`, then an
unsigned Release build. The fixtures never change networking or install a
driver. Testing a signed driver on hardware is a separate, deliberate step and
requires a recovery network path.

Changes to release scripts and workflows need particular care: release jobs
have access to signing credentials. Keep unsigned pull-request CI separate
from signing, pin third-party Actions, and never expose secrets or raw signing
logs. See [DISTRIBUTION.md](DISTRIBUTION.md).

The name **Lekuo Control** identifies this independent community project. Its
original icon is generated by `swift scripts/render_brand.swift`; update the
SVG and complete AppIcon asset set together. Preserve third-party license
notices and the vendor non-affiliation statement.
